# סוכן שירות לקוחות — LangGraph

פרויקט לימודי בסיסי המדגים בניית agent עם LangGraph, הכולל שיחה עם משתמש, קריאה לכלים (tools), ענף החלטה מותנה, וזיכרון שיחה.

## מה הפרויקט עושה

הפרויקט מממש **סוכן שירות לקוחות** שיודע:
- לענות על שאלות כלליות בשיחה חופשית
- לבדוק **סטטוס הזמנה** לפי מספר הזמנה (`lookup_order`)
- לספק מידע על **מדיניות החזרות** (`return_policy`)
- **לזכור** את הקשר השיחה בין הודעה להודעה

## מושגי LangGraph שמודגמים

| מושג | איפה זה בקוד |
|---|---|
| **State** | `class State(TypedDict)` — מחזיק את היסטוריית ההודעות |
| **Tools** | `lookup_order`, `return_policy` — פונקציות שהמודל יכול לקרוא להן |
| **Conditional Edge** | `tools_condition` — מחליט אם לפנות לכלי או לסיים |
| **Memory** | `MemorySaver` — checkpointer ששומר את השיחה לפי `thread_id` |

## מבנה הגרף

```
START → chatbot → (יש קריאה לכלי? ) → tools → chatbot → END
                  → (אין קריאה לכלי) → END
```

## התקנה והרצה

```bash
python -m venv venv
venv\Scripts\Activate.ps1        # Windows
# source venv/bin/activate       # Mac/Linux

pip install -r requirements.txt
```

צרי קובץ `.env` (לפי הדוגמה ב-`.env.example`) עם מפתח ה-API:
```
ANTHROPIC_API_KEY=your_key_here
```

הרצה:
```bash
python support_agent.py
```

## דוגמאות שיחה

```
את/ה: מה קורה עם הזמנה 1001?
Bot: הזמנה 1001: אוזניות אלחוטיות — סטטוס: נשלח, זמן משלוח: 3 ימי עסקים

את/ה: מה מדיניות ההחזרות שלכם?
Bot: ניתן להחזיר מוצרים תוך 14 יום מהרכישה, באריזה מקורית ועם חשבונית.
     מוצרי אלקטרוניקה שנפתחו ניתנים להחזרה רק אם יש בהם תקלה.

את/ה: ומה עם הזמנה 1002?
Bot: הזמנה 1002: מקלדת מכנית — סטטוס: בטיפול, זמן משלוח: טרם נשלח
```
